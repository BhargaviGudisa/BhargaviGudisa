### What I work on

- **Infrastructure as code** — Terraform-provisioned GCP storage, compute and service
  accounts, so every Linux environment runs the same version-controlled build instead of
  drifting apart. The difference between dev and production is a variables file, not a
  different procedure.
- **Containerized pipelines** — Python and Bash ingestion applications in Docker on Linux
  VMs, with the runtime and system dependencies fixed at build time rather than inherited
  from whichever host happens to run them.
- **AI quality systems** — tooling that evaluated 5,000+ AI responses at 98% flagging
  accuracy, with a root-cause process separating content gaps from prompt-handling
  failures so each failure reaches the one team that can fix it.
- **Content governance** — owner-per-area accountability plus automated Bash audits that
  route 200+ stale entries a month to the people who own them.
